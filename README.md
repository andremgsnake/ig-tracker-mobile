# IG Tracker Mobile

PWA mobile per gestione contenuti Instagram.

## App
https://andremgsnake.github.io/ig-tracker-mobile/

## Backend downloader
Il backend si trova in `backend/` ed è configurato tramite `render.yaml`.

[Deploy to Render](https://render.com/deploy?repo=https://github.com/andremgsnake/ig-tracker-mobile)

Il downloader è pensato per contenuti Instagram pubblici e va usato solo per contenuti propri o per cui si dispone dell'autorizzazione al download.
